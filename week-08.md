# Week 8: Place Tags fa fe fi fo fu

## Vocabulary to Learn

**New gismu (8):**
- spuda — x1 replies/responds to x2 with response x3
- retsku — x1 asks/requests x2 (information) from x3 about x4
- stidi — x1 suggests/proposes x2 to audience x3
- smadi — x1 guesses/conjectures x2 is true about x3
- jimpe — x1 understands/comprehends x2 about subject x3
- pensi — x1 thinks/ponders about x2
- nitcu — x1 needs x2 for purpose x3
- kakne — x1 is capable/able to do x2 under conditions x3

## Grammar to Learn

**Place Tags — Explicit Place Marking:**
- `fa` marks x1 (first place)
- `fe` marks x2 (second place)
- `fi` marks x3 (third place)
- `fo` marks x4 (fourth place)
- `fu` marks x5 (fifth place)
- Fill places in ANY order: `fi la .alis. fa mi cu dunda fe la .cukta.`
- Mix tags and positional: tag some places, leave others in default order
- When tags beat conversion: more explicit, no mental gymnastics
- se vs fa/fe: stylistic choice — conversion emphasizes, tags specify

## Vocabulary to Refresh

All 64 gismu from weeks 1-7, with focus on:
- Multi-place predicates (klama, dunda, vecnu, benji, notci, mrilu)
- Verbs where place order matters

## Grammar to Refresh

- se/te/ve/xe conversion system
- Place structure fundamentals
- zo'e for unspecified places

## Conversation Topics

Practice using place tags instead of conversion:
- Rephrase "Alice receives the book from me" using fi/fa/fe
- Ask questions with explicit place tags
- Describe scenarios where place order is non-standard

## Day 1 — Introduction to fa and fe

**15-min practice:**
- Learn spuda, retsku (5 min)
- Understand fa (marks x1) and fe (marks x2) (5 min)
- Practice: `fe la .cukta. fa mi cu dunda fi la .alis.` (5 min)
- Example: Same as `mi dunda la .cukta. la .alis.` but with explicit tags

## Day 2 — Adding fi for Third Place

**15-min practice:**
- Learn stidi, smadi (5 min)
- Practice fi (marks x3) (5 min)
- Drill: `fi la .alis. fa mi cu dunda fe la .cukta.` — I give the book to Alice (5 min)
- Compare with `te dunda`: which is clearer?

## Day 3 — fo for Fourth Place

**15-min practice:**
- Learn jimpe, pensi (5 min)
- Practice fo (marks x4) with vecnu and benji (5 min)
- Example: `fo la .skami. fa mi cu benji fe la .notci. fi do` (5 min)
- I send the message to you via computer

## Day 4 — fu for Fifth Place

**15-min practice:**
- Learn nitcu, kakne (5 min)
- Practice fu (marks x5) with klama (5 min)
- Example: `fu la .karce. fa mi cu klama fe la .paris.` — I go to Paris by car (5 min)
- Review: all five place tags

## Day 5 — Mixing Tags and Positional

**15-min practice:**
- Review all 8 new gismu (5 min)
- Practice: `fa mi cu dunda la .cukta. fi la .alis.` (tag x1, leave x2 positional, tag x3) (5 min)
- Drill: when can you skip tags? (5 min)
- Rule: once you use a tag, everything after needs tags or returns to positional

## Day 6 — Tags vs Conversion

**15-min practice:**
- Compare: `te dunda` vs `fi` tagging (5 min)
- Practice both methods with same sentences (5 min)
- Stylistic choice: tags are explicit, conversion is concise (5 min)
- Example: `la .alis. te dunda la .cukta. mi` vs `fi la .alis. fa mi cu dunda fe la .cukta.`

## Day 7 — Full Week Review

**15-min practice:**
- Flashcard drill: all 8 new gismu (5 min)
- Translate English sentences using place tags instead of conversion (5 min)
- Conversation: ask and answer questions using retsku with place tags (5 min)
- Example: `fi ma fa do cu retsku fe la .notci.` — About what do you ask for the message?
