# Week 01 — Sounds, Words & Your First Bridi

## 1. Vocabulary to Learn (12 gismu)

- **prami** — love
- **klama** — go
- **tavla** — talk
- **citka** — eat
- **pinxe** — drink
- **cadzu** — walk
- **ciska** — write
- **tcidu** — read
- **sipna** — sleep
- **melbi** — beautiful
- **xamgu** — good
- **xlali** — bad

## 2. Grammar to Learn

- **Phonology:** Lojban has 6 vowels (a e i o u y), diphthongs (ai ei oi au). Consonants are like English. Stress is always on the penultimate syllable. The period (.) is a glottal stop/pause.
- **Three word types:** gismu (root words, 5 letters like `klama`), cmavo (grammar words, short like `mi`, `cu`), cmevla (names, end in consonant like `.alis.`)
- **Bridi structure:** A bridi is a claim: selbri (relation) + sumti (arguments). Example: `mi prami do` = I love you
- **`cu` marker:** `cu` marks the start of the selbri
- **`.i` separator:** `.i` separates sentences
- **Pronouns:** mi (I/me), do (you), ti (this here), ta (that there), tu (that yonder)

## Daily Breakdown

### Day 1 — Vowels and Basic Sounds

- Practice pronouncing all 6 vowels (a e i o u y)
- Practice common diphthongs: ai, ei, oi, au
- Say each of the 12 gismu aloud, stressing the penultimate syllable
- Note which sounds feel unfamiliar

### Day 2 — First Pronouns and Simple Bridi

- Memorize: mi (I), do (you), ti (this)
- Build 5 simple bridi: `mi [gismu]` using prami, klama, tavla, citka, pinxe
- Practice saying them aloud
- Notice the pattern: pronoun + verb-like-word

### Day 3 — Adding a Second Sumti

- Practice: `mi prami do`, `mi tavla do`, `mi pinxe ti`
- Try all 12 gismu in the pattern `mi [verb] do` or `mi [verb] ti`
- Some won't make sense yet — that's okay
- Focus on the rhythm and flow

### Day 4 — The `cu` Marker

- Learn what `cu` does: marks the start of the selbri
- Practice: `mi cu prami do`, `mi cu klama`, `do cu citka`
- Compare with and without `cu` — notice it's optional when clear
- Try 6 sentences using `cu` explicitly

### Day 5 — Sentence Separator `.i`

- Practice chaining sentences: `mi tavla .i do citka`
- Create 4 two-sentence chains using `.i`
- Example: `mi cadzu .i do sipna` (I walk. You sleep.)
- Pause clearly at `.i`

### Day 6 — Vocabulary Drill

- Review all 12 gismu — write them down from memory
- For each one, say `mi [verb]` aloud
- Test yourself: cover the English, see if you remember the meaning
- Focus on the ones you keep forgetting

### Day 7 — Free Practice and Review

- Create 5 original bridi using any gismu from this week
- Practice describing your current state: `mi sipna` or `mi citka`
- Say 3 things about someone else using `do`
- Review any grammar points that felt confusing
