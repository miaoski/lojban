## New Material (5-7 min)

### More Attitudinals

| Cmavo | Emotion | Usage |
|-------|---------|-------|
| `.a'o` | hope | `.a'o do snada` (I hope you succeed) |
| `.au` | desire | `.au mi citka` (I want to eat) |
| `.e'e` | encouragement | `.e'e do troci` (You can do it!) |
| `.ie` | agreement | `.ie do drani` (I agree, you're right) |
| `.ienai` | disagreement | `.ienai ti jitfa` (I disagree, this is false) |

### Hope and Desire

```
.a'o do klama
```
I hope you go.

```
.au mi sipna
```
I want to sleep.

### Agreement and Disagreement

```
.ie
```
I agree. / Yes, that's right.

```
.ienai
```
I disagree. / No, that's wrong.

### Encouragement

```
.e'e do troci
```
Go for it! You try!

```
.e'e
```
You can do it!

### Key Point

> `.a'o` expresses hope, `.au` desire, `.ie` agreement, `.e'e` encouragement.

## Practice (4-5 min)

### Exercise 1: Add Emotions

Add appropriate attitudinal:

1. I hope you succeed. → ?

</details>
