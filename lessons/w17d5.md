# Week 17 · Day 5 — xo for Number Questions

> **Today's goal:** Learn `xo` to ask about quantities.
> **Time:** 15 minutes

---

## Warm-up (2-3 min)

Question word review:

```
ma asks about → ?
mo asks about → ?
```

(Answers: sumti (who/what), selbri (what is/does))

---

## New Material (5-7 min)

### What Is `xo`?

`xo` replaces a **number** to ask "how many?"

### Basic Usage

```
xo gerku
```
How many dogs?

```
do ponse xo cukta
```
You own how many books?

### Examples

```
xo prenu cu klama
```
How many people go?

```
ti jdima xo
```
This costs how much?

```
do viska xo mlatu
```
You see how many cats?

### Answering `xo` Questions

Replace `xo` with a number:

**Q:** `do ponse xo cukta`
**A:** `mi ponse mu cukta` (I own five books.)

**Q:** `xo gerku cu cadzu`
**A:** `re gerku cu cadzu` (Two dogs walk.)

### Key Point

> `xo` asks "how many?" — answer by replacing `xo` with a number.

## Practice (4-5 min)

### Exercise 1: Form xo Questions

Create questions:

1. How many dogs? → ?
2. You own how many books? → ?
3. How many people go? → ?

<details>
<summary>Answers</summary>

1. `xo gerku`
2. `do ponse xo cukta`
3. `xo prenu cu klama`

</details>

### Exercise 2: Answer xo Questions

Answer:

1. `xo gerku cu cadzu` — Three dogs walk.
2. `do ponse xo cukta` — I own ten books.
3. `xo prenu cu tavla` — Five people talk.

<details>
<summary>Answers</summary>

1. `ci gerku cu cadzu`
2. `mi ponse pa no cukta`
3. `mu prenu cu tavla`

</details>

### Exercise 3: Mixed Questions

Translate:

1. How many apples do you eat?
2. How many hours do you work?
3. How many days in a week?

<details>
<summary>Answers</summary>

1. `do citka xo plise`
2. `do gunka xo cacra`
3. `xo djedi fa pa jeftu` or `lo jeftu cu xo djedi`

</details>
