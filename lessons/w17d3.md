## New Material (5-7 min)

### What Is `ma`?

`ma` is a question word that replaces **any sumti** (argument).

### `ma` in Different Places

**x1 position:**
```
ma klama
```
Who/what goes?

**x2 position:**
```
do klama ma
```
Where do you go? (You go to what?)

**x3 position:**
```
do dunda ti ma
```
To whom do you give this?

### Examples

```
ma citka lo plise
```
Who eats the apple?

```
do nelci ma
```
What do you like?

```
do dunda ma mi
```
What do you give me?

### Answering `ma` Questions

Replace `ma` with the answer:

**Q:** `do klama ma`
**A:** `mi klama la .paris.` (I go to Paris.)

**Q:** `ma tavla do`
**A:** `la .bob. cu tavla mi` (Bob talks to me.)

### Key Point

> `ma` asks "who?" or "what?" — replace it with a sumti to answer.
