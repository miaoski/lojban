## New Material (5-7 min)

### New Vocabulary

| Lojban | Place Structure | English |
|--------|----------------|---------|
| `djedi` | x1 is a day of week/month x2 | day |
| `jeftu` | x1 is a week of month/year x2 | week |
| `masti` | x1 is a month of year x2 | month |
| `nanca` | x1 is a year | year |
| `cacra` | x1 is an hour | hour |

### Using Time Words

```
ti djedi
```
This is a day.

```
mi gunka pa jeftu
```
I work one week.

```
la .alis. cu xabju ti re nanca
```
Alice lives here two years.

### With Numbers

```
ci djedi
```
Three days.

```
re jeftu
```
Two weeks.

```
pa re masti
```
Twelve months.

### Key Point

> These words name time periods. Use numbers to quantify them.

2. I study one year.

<details>
<summary>Answers</summary>

2. `mi tadni pa nanca`
3. `mi sipna bi cacra`

</details>

### Exercise 3: Complex Sentences

2. `lo jeftu cu clani`
3. `pa cacra cu tordu`

</details>
