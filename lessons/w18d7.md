## Grammar Summary (3-4 min)

### Attitudinals (Emotions)

| Cmavo | Emotion |
|-------|---------|
| `.ui` | happiness |
| `.uinai` | unhappiness |
| `.uu` | pity |
| `.u'i` | amusement |
| `.oi` | pain |
| `.a'o` | hope |
| `.au` | desire |
| `.e'e` | encouragement |
| `.ie` | agreement |
| `.ienai` | disagreement |

### Intensity Modifiers

| Modifier | Level |
|----------|-------|
| `cai` | extreme |
| `sai` | strong |
| `ru'e` | weak |
| `cu'i` | neutral |
| `nai` | opposite |

### Evidentials (Knowledge Source)

| Cmavo | Source |
|-------|--------|
| `ba'a` | expectation |
| `ti'e` | hearsay |
| `za'a` | observation |
| `pe'i` | opinion |
| `ju'o` | certainty |

## Integration Challenge (1-2 min)

### Tell an Emotional Story

Use at least:
- Three different attitudinals
- Two evidentials
- One intensity modifier

**Example:**
```
ti'e la .alis. pu snada .uisai
.i za'a .a'o ri ba ze'u gleki
.i pe'i .ie la .alis. cu drani
.i .uicai mi tugni
```

(I heard Alice succeeded. Very happy! I observe, hope, she will be happy long-term. In my opinion, I agree, Alice is right. Ecstatic! I agree.)

Create your own and say it aloud.
