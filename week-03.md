# Week 03 — Numbers & Yes/No Questions

## 1. Vocabulary to Learn (8 gismu)

- **cmalu** — small
- **gleki** — happy
- **badri** — sad
- **nelci** — like
- **djica** — want
- **gerku** — dog
- **mlatu** — cat
- **plise** — apple

## 2. Grammar to Learn

- **Digits:** no (0), pa (1), re (2), ci (3), vo (4), mu (5), xa (6), ze (7), bi (8), so (9)
- **Compound numbers:** String digits together — pa no (10), re vo (24), pa no no (100)
- **Yes/no questions:** `xu` makes any bridi a yes/no question
  - `xu do klama` — Are you going?
- **Answering:**
  - `go'i` — yes/reaffirm the bridi
  - `na go'i` — no/deny the bridi

## 3. Vocabulary to Refresh

- **Week 1:** prami, klama, tavla, citka, pinxe, cadzu, ciska, tcidu, sipna, melbi, xamgu, xlali
- **Week 2:** cmene, prenu, nanmu, ninmu, verba, zdani, sutra, barda

## 4. Grammar to Refresh

- Bridi structure
- `la` for names
- Vocatives: coi, co'o, ki'e, je'e, mi'e
- `cu` marker
- `.i` separator

## 5. Conversation Topics

- Ask "Do you like [thing]?"
- Answer yes/no questions
- Count objects
- Say your age

**Example sentence:** `xu do nelci la .mlatu.` — Do you like cats?

## Daily Breakdown

### Day 1 — Learning Digits 0-9

- Memorize: no pa re ci vo mu xa ze bi so
- Practice counting 0-9 aloud five times
- Write the digits from memory
- Practice random digits: ci, ze, mu, pa

### Day 2 — Compound Numbers

- Learn the pattern: string digits together
- Practice: pa no (10), re no (20), ci no (30)
- Count: pa, re, ci... up to pa no
- Try: re vo (24), vo mu (45), so so (99)

### Day 3 — Emotions and Small/Big

- Learn: gleki (happy), badri (sad), cmalu (small)
- Practice: `mi gleki`, `do badri`, `ti cmalu`
- Combine: `la .bob. cu gleki`, `ti gerku cu barda`
- Create 5 sentences about emotions

### Day 4 — Like and Want

- Learn: nelci (like), djica (want)
- Practice: `mi nelci ti`, `do djica la plise`
- Combine with animals: `mi nelci la gerku`, `do nelci la mlatu`
- Make 5 statements about things you like/want

### Day 5 — Yes/No Questions with `xu`

- Learn: `xu` turns any bridi into a yes/no question
- Practice: `xu do klama`, `xu mi gleki`, `xu ti plise`
- Ask 5 questions using `xu` with Week 1-2 gismu
- Example: `xu la .alis. cu prami do`

### Day 6 — Answering with `go'i`

- Learn: `go'i` (yes/affirm), `na go'i` (no/deny)
- Practice Q&A pairs:
  - `xu do nelci la mlatu` — `go'i` (yes)
  - `xu ti barda` — `na go'i` (no)
- Create 5 question-answer exchanges

### Day 7 — Numbers and Questions Combined

- Count animals: `pa gerku`, `re mlatu`, `ci plise`
- Ask about quantities: `xu ti re plise` (Are these two apples?)
- Practice: `mi djica ci plise` (I want three apples)
- Review all digits, `xu`, `go'i`, and Week 3 gismu
