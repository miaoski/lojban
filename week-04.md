# Week 04 — What Place Structure Means

## 1. Vocabulary to Learn (10 gismu)

- **dunda** — x1 gives x2 to x3
- **vecnu** — x1 sells x2 to x3 for x4
- **lebna** — x1 takes x2 from x3
- **bajra** — x1 runs
- **viska** — x1 sees x2
- **tirna** — x1 hears x2
- **penmi** — x1 meets x2
- **djuno** — x1 knows x2 about x3
- **cusku** — x1 says x2 to x3
- **benji** — x1 sends x2 to x3

## 2. Grammar to Learn

- **Place structure concept:** Every gismu has a fixed place structure
  - Example: klama has x1 (goer) x2 (destination) x3 (origin) x4 (route) x5 (vehicle)
- **The definition IS the place order** — you must look it up for each gismu
- **Filling places:** Places are filled left to right
  - `mi klama la .paris.` → x1=mi, x2=la .paris.
- **`zo'e` for unspecified:** Skip a place without confusing the order
  - `mi klama zo'e la .london.` → x1=mi, x2=unspecified, x3=la .london.

## 3. Vocabulary to Refresh

- **Week 1:** prami, klama, tavla, citka, pinxe, cadzu, ciska, tcidu, sipna, melbi, xamgu, xlali
- **Week 2:** cmene, prenu, nanmu, ninmu, verba, zdani, sutra, barda
- **Week 3:** cmalu, gleki, badri, nelci, djica, gerku, mlatu, plise

## 4. Grammar to Refresh

- Bridi structure
- `la` for names
- Numbers (no through so)
- `xu` for questions
- `go'i` for answers

## 5. Conversation Topics

- "I give [thing] to [person]"
- "I see [thing]"
- "I know [fact]"
- Using multiple places in one sentence

**Example sentence:** `mi klama la .paris. la .london.` — I go to Paris from London.

## Daily Breakdown

### Day 1 — Understanding Place Structure

- Learn the concept: each gismu has numbered slots (x1, x2, x3...)
- Study klama's 5 places: goer, destination, origin, route, vehicle
- Practice filling 2 places: `mi klama la .paris.` (x1, x2)
- Practice filling 3 places: `mi klama la .paris. la .london.` (x1, x2, x3)

### Day 2 — Two-Place Predicates

- Learn: viska (x1 sees x2), tirna (x1 hears x2), penmi (x1 meets x2)
- Practice: `mi viska do`, `do tirna la gerku`, `mi penmi la .alis.`
- Create 6 sentences using these three gismu
- Focus on which sumti goes in which position

### Day 3 — Three-Place Predicates

- Learn: dunda (x1 gives x2 to x3), cusku (x1 says x2 to x3)
- Practice: `mi dunda la plise la .bob.` (I give an apple to Bob)
- Practice: `mi cusku ti do` (I say this to you)
- Create 5 three-place sentences

### Day 4 — The `zo'e` Placeholder

- Learn: `zo'e` means "something unspecified in this place"
- Practice skipping x2: `mi klama zo'e la .london.` (I go [somewhere] from London)
- Practice skipping x3: `mi dunda la plise zo'e` (I give an apple [to someone])
- Create 4 sentences using `zo'e` to skip places

### Day 5 — Four-Place: vecnu

- Learn: vecnu (x1 sells x2 to x3 for x4)
- Practice: `mi vecnu ti do` (I sell this to you [for something])
- Practice: `la .bob. cu vecnu la plise la .alis.` (Bob sells an apple to Alice)
- Try filling all 4 places (you'll need Week 5 vocab for price, but try with `zo'e`)

### Day 6 — More Three-Place Practice

- Learn: lebna (x1 takes x2 from x3), benji (x1 sends x2 to x3)
- Practice: `mi lebna la plise la .bob.` (I take an apple from Bob)
- Practice: `mi benji ti do` (I send this to you)
- Create 6 sentences mixing all three-place gismu learned

### Day 7 — Integration and Review

- Take 5 gismu from this week
- Write out their place structures from memory
- Create one sentence for each, filling at least 2 places
- Practice using `zo'e` when you want to skip a place
- Review the concept: left-to-right filling, order matters
