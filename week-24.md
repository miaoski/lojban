# Week 24 — Quotation & Discursives

## 1. Vocabulary to Learn

- **sarji** — x1 supports/holds up x2 against x3 (force) with x4
- **sidju** — x1 helps/assists/aids x2 to do/achieve x3
- **rivbi** — x1 avoids/evades/shuns x2 (event/situation)
- **bilma** — x1 is ill/sick with disease x2
- **kanro** — x1 is healthy/fit/well
- **speni** — x1 is married to x2 by law/custom x3
- **gunka** — x1 works on/at x2 (activity)
- **denpa** — x1 waits/awaits x2 at/in state x3

## 2. Grammar to Learn

**Quotation** — Referring to text itself, not its meaning:

**Grammatical Quotes:**
- **lu ... li'u** — quotes valid Lojban text
  - `la .alis. cusku lu coi li'u` (Alice says "hello")
  - The quoted text must be grammatical Lojban
  - Can quote full sentences: `lu mi klama li'u cu jufra` ("I go" is a sentence)

- **zo** — quotes single word
  - `zo mlatu cu valsi` (the-word "mlatu" is a word)
  - Much shorter than lu...li'u for single words
  - Only works with single word tokens

**Non-grammatical Quotes:**
- **lo'u ... le'u** — error/foreign quote (anything goes)
  - `lo'u Hello, world! le'u` (quotes non-Lojban text)
  - Use for foreign languages, errors, or malformed text
  - No validation of contents

**Referent/Symbol:**
- **la'e** — the referent of (what it refers to)
  - `mi lebna la'e zo .rodo.` (I take what-"Rodeau"-refers-to = I take Rodeau)

- **lu'e** — a symbol/word for (the other direction)
  - `mi ciska lu'e la .rodo.` (I write a-symbol-for Rodeau = I write "Rodeau")

**Discursives** — Metalinguistic comments on your own text:

- **ku'i** — however/but (contrast): `mi klama .i ku'i do stali` (I go. But you stay.)
- **ji'a** — additionally/also: `mi ji'a nelci` (I also like)
- **po'o** — only/just: `mi po'o klama` (I only go / only I go)
- **mu'a** — for example: `lo plise mu'a` (apples, for example)
- **ta'o** — by the way/incidentally: `ta'o do klama` (by the way, you go)
- **to'u** — in other words: `mi tatpi to'u mi djica lo nu sipna` (I'm tired, in-other-words I want to sleep)
- **mi'u** — ditto/same as before

Discursives don't affect the logic of the sentence; they're commentary.

## 3. Vocabulary to Refresh

Focus on communication verbs:
- **cusku** — express/say
- **tavla** — talk
- **bacru** — utter
- **ciska** — write
- **tcidu** — read
- **xusra** — assert/claim
- **tugni** — agree
- **natfe** — deny
- **retsku** — ask/request
- **spuda** — respond

## 4. Grammar to Refresh

- **Bridi structure** — Quotation creates sumti from text
- **Abstraction (nu/du'u)** — Compare with quotation
- **Sumti** — Quoted text becomes a sumti
- **.i separator** — Discursives often follow it

## 5. Conversation Topics

Practice:
- Reporting what someone said: "Alice says 'hello'"
- Talking about words: "The word 'mlatu' means cat"
- Using discursives: "I like apples. However, I prefer oranges."
- Giving examples: "I like fruits, for example apples."
- Expressing contrast: "I want to go, but I must stay."

## Day 1 — Grammatical Quotes: lu...li'u

**15 min:** Learn to quote valid Lojban with lu...li'u.

- Read grammar section on lu...li'u
- Memorize: sarji, sidju
- Practice: `la .alis. cusku lu coi li'u` (Alice says "hello")
- Practice: `lu mi klama li'u cu jufra` ("I go" is a sentence)
- Build 3 sentences quoting Lojban text

## Day 2 — Single Word Quotes: zo

**15 min:** Learn to quote single words with zo.

- Read grammar section on zo
- Memorize: rivbi, bilma
- Practice: `zo mlatu cu valsi` (the-word "mlatu" is a word)
- Practice: `mi nelci zo .lojban.` (I like the-word "Lojban")
- Build 3 sentences using zo to quote single words

## Day 3 — Foreign Quotes: lo'u...le'u

**15 min:** Learn to quote non-Lojban text.

- Read grammar section on lo'u...le'u
- Memorize: kanro, speni
- Practice: `lo'u Hello! le'u cu glibau jufra` ("Hello!" is an English sentence)
- Use for English, errors, or anything non-Lojban
- Build 3 sentences quoting foreign/error text

## Day 4 — Referent & Symbol: la'e, lu'e

**15 min:** Learn to reference vs symbolize.

- Read grammar section on la'e and lu'e
- Memorize: gunka, denpa
- Practice: `mi lebna la'e zo .rodo.` (I take what-"Rodeau"-refers-to)
- Practice: `mi ciska lu'e la .rodo.` (I write a-symbol-for Rodeau)
- Build 3 sentences using la'e or lu'e

## Day 5 — Discursives: ku'i, ji'a, po'o

**15 min:** Learn discourse markers.

- Read grammar section on discursives
- Review all 8 vocabulary words
- Practice: `mi klama .i ku'i do stali` (I go. However, you stay.)
- Practice: `mi ji'a nelci` (I also like)
- Practice: `mi po'o djica` (I only want / only I want)
- Build 3 sentences with different discursives

## Day 6 — More Discursives: mu'a, ta'o, to'u

**15 min:** Learn example and comment markers.

- Read sections on mu'a, ta'o, to'u
- Practice: `lo plise mu'a` (apples, for example)
- Practice: `ta'o do klama` (by the way, you go)
- Practice: `mi tatpi to'u mi djica lo nu sipna` (I'm tired, in-other-words I want to sleep)
- Build 3 sentences with mu'a, ta'o, or to'u

## Day 7 — Review and Integration

**15 min:** Comprehensive review of week 24 material.

- Quiz yourself on all 8 vocabulary words
- Write 3 sentences using quotation (lu...li'u, zo, lo'u...le'u)
- Write 3 sentences using discursives
- Practice reporting speech: "She said that I should go" using both quotation and abstraction
- Review: quotation vs abstraction (lu...li'u vs du'u)
